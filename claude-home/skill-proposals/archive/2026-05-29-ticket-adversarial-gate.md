# Skill Proposal: ticket-adversarial-gate
Date: 2026-05-29
Source: DOOH Toronto ticket creation session

## Trigger
After creating 3+ tickets for an epic or feature, before adding to sprint.

## Scope
global (applies to any org's ticket creation)

## Draft Steps
1. Accept list of newly created ticket keys
2. Read all ticket descriptions and ACs
3. Dispatch independent adversarial agent (Opus) to challenge: proportionality, unnecessary fragmentation, premature cross-cutting concerns, blocked work in sprint, missing risks
4. Present findings with severity ratings
5. On approval, execute restructuring (merge tickets, re-estimate, move blocked work to backlog)
6. Update Jira comments on affected tickets
7. Verify ADR alignment for architecture-dependent ACs
