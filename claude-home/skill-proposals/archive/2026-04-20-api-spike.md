# Skill Proposal: api-spike
Date: 2026-04-20 (merged from api-schema-probe + external-api-spike-validation)
Source: KTP-522 Goldfish Ads API spike

## Trigger
When integrating with an undocumented or poorly documented external API. "API spike", "validate API", "test API credentials", "explore API", "reverse-engineer this API."

## Scope
Global (any org, any external API)

## Draft Steps

### Phase 1: Auth Probe
1. Send request with invalid credentials → confirm auth mechanism (expect 401/403)
2. Send valid credentials to a known endpoint → confirm auth works
3. Document: auth type (API key header, Bearer, Basic), header name, token format

### Phase 2: API Shape Discovery
1. GET parent resource paths before sub-paths
2. Probe discovery endpoints (/v2/types, /v2/status, /v2/publishers, etc.)
3. Map the API surface: which paths exist, which return 404/410
4. Try adjacent variants: if POST /resource/by-X fails, try GET with query params, try different HTTP methods

### Phase 3: Schema Reverse Engineering
1. Send empty body → read error message for required fields
2. Add one field at a time → watch for error message changes (422 text shifting = field accepted)
3. For each discovered field, try common formats (string, int, nested object, array)
4. Watch for: 422 → 500 means value format wrong but field name right. 204 = empty data, not error. 410 = deprecated version.

### Phase 4: Document and Report
1. Produce structured report: confirmed fields, inferred types, unknown formats, blocker classification
2. Generate reusable Python/curl script capturing the working request shape
3. Save working payloads immediately. Document non-working endpoints with exact error.
4. Go/No-Go recommendation with evidence

## Key Rules
- Never declare BLOCKED after one endpoint variant. Explore at least 3 adjacent paths first.
- Error messages are documentation. Read them carefully, they often describe the correct format.
- 500 means auth passed, business logic crashed. That's progress, not failure.
- Save every working payload the moment it works. APIs change.
