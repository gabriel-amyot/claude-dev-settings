# Skill Proposal: nx crawl (subcommand, not a new skill)
Date: 2026-08-12
Source: session deft-pike — first sync of notion-checkout (232 pages)

## Trigger

"Sync Notion", "refresh the mirror", "crawl the workspace" — any request to populate or refresh
`notion-checkout` with more than a handful of pages.

`keen-shrike`'s gap list already named this: *"no workspace crawler."* This session built the
missing pieces by hand and they should not stay hand-assembled.

## Scope

Repo-local to the `notion` skill: a `crawl` subcommand on `nx.py`, plus the existing
`fetch-shard.sh`. **Not** a new top-level skill — the `notion` skill already owns this territory and
a second entry point would split it.

## What exists after this session

- `~/.claude/skills/notion/fetch-shard.sh` — fetches one shard via an isolated `claude -p`, Sonnet
  by default, Bash-only writes, presigned-URL scrubbing, secret withholding. Working.
- `~/.claude/skills/notion/nx_pull.py` — deterministic REST-API puller. Written, compiles,
  **untested** (blocked on an admin token).
- The driver loop itself was ad-hoc: `split -l 3`, a generated cmds file, `xargs -P 5`, `nohup`.
  That is the part that should be codified.

## Draft Steps

1. `nx crawl --ids <file> [--shard-size 3] [--parallel 5] [--model sonnet]`
   - Shards the id list, generates the command list, runs it under a bounded parallel driver,
     detached so no 10-minute tool ceiling can kill it.
2. **Prefer the deterministic path when available.** If `$NOTION_TOKEN` is set, call `nx_pull.py`
   and skip the model entirely. Fall back to `fetch-shard.sh` only without a token. This is the
   whole point: the MCP path should become the fallback, not the default.
3. **Resume by default.** Skip ids already present in staging or already current in the catalog.
   The crawl was interrupted twice this session; resumability was hand-rolled both times.
4. **Progress that does not lie.** Count staged records, never redirect-created shard files
   (`find -size +1c`). Report cost by summing `total_cost_usd` from shard results.
5. **Validate before promoting.** Shape check, filename/id match, credential scan across staged
   records. Refuse to hand off to `ingest` on any failure. This ran as an ad-hoc python one-liner
   three separate times.
6. Hand the run to `nx ingest <run_id>`, and **never** pass `--full` automatically — completeness is
   a claim only the caller can justify.

## Why it is worth codifying

The manual version cost 3 silently-lost pages (Write-tool hook block), one wasted Opus pilot, and
two interruption recoveries. Every one of those is a defect the codified version prevents by
construction rather than by the operator remembering.
