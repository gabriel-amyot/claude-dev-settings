# Cue sheet — "How I use AI, day to day"

Open `deck.html`. Full-screen the browser. Keep the folder together — the deck loads `assets/proof.png`. No network needed, no libraries.

## Controls

| Key | Action |
|---|---|
| `→` `space` `click` | Next **reveal**, then next slide |
| `←` | Back one reveal, then back one slide |
| `T` | Start / pause the presenter timer |
| `N` | Speaker notes |
| `R` | Reset timer |
| `H` | Hide the timer HUD before screensharing |
| `1`–`9` | Jump to slide |
| `Esc` | Close any overlay |

**Press `T` when you start.** The HUD shows elapsed / planned with a chip: green on time, orange slipping, red cut something.

## Slide 2 is now the expandable hub

Three of the six rows open up on click. This is where the depth lives, on demand, so the linear deck stays short.

| Click | Opens |
|---|---|
| **LIBRARY** | Your real knowledge graph — 330 mapped pages, 1,227 links, animated out from centre, coloured by section |
| **CREW** | The four roles: Leo, Winston, Amelia, Quinn, plus the "best thing I own is not code generation" line |
| **LINES** | The full list of 118 skills |

`Esc` or click to close. Slides 5 and 6 also enlarge their diagrams on click.

## If you run long

1. **Slide 6** (nothing ships on a claim). Slide 8 carries the proof theme. Saves 40s.
2. **Slide 3**, skip the folder tree and talk only the three tiers. Saves ~20s.
3. **Slide 2**, open only the LIBRARY row, skip CREW and LINES. Saves ~20s.
4. **Slide 10**, drop to one failure card. Saves ~20s.

Do not cut 4, 7, 11, 12, or 13. Those carry the argument.
