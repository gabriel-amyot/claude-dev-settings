# Tracking

- [Pilot](https://github.com/gabriel-amyot/claude-dev-settings/issues/1): Scope and acceptance criteria.
- [Local measurements](https://github.com/gabriel-amyot/claude-dev-settings/issues/2): API latency, reliability, and resource evidence.
- [Library replay](https://github.com/gabriel-amyot/claude-dev-settings/issues/3): Frozen source and retrieval comparisons.
- [Independent evaluation](https://github.com/gabriel-amyot/claude-dev-settings/issues/4): Held-out labels and later decision.
- [publication-audit.json](publication-audit.json): Published targets, draft hashes, and authorization.
- [archive-post-audit.json](archive-post-audit.json): Five archive comments, their hashes, authorization, and verified remote readback.
- `archive-issue-*.md` / `archive-issue-*.rendered.md`: Retained archive comment drafts and full rendered previews.
- [Draft implementation review](https://github.com/gabriel-amyot/claude-dev-settings/pull/5): Pilot code and evidence boundaries.
- [pull-request.md](pull-request.md): Draft review description.
- `*.md` / `*.rendered.md`: Retained issue drafts and body-preserving template.

Issues stay open while evidence requirements remain unmet. Predictions never close an issue automatically.
