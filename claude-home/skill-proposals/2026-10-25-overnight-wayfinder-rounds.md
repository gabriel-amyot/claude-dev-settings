# Skill Proposal: overnight-wayfinder-rounds
Date: 2026-10-25
Source: proxi-cloud-wayfinder (Proxi Mac → GCP)

## Trigger
"work overnight on this map", "run another round", long multi-night efforts tracked by a wayfinder map where the destination is a live system.

## Scope
global (Klever-first)

## Draft Steps
1. Charter file (HANDOFF.md) with destination, verified facts, explicit authority, hard rules and incident rules; every agent reads it first; append decisions as dated sections.
2. Round workflow: fixed or replanned task list, ORDERED loop (hard deps only), implementer → QA (live proof) → bounded fix → unblock spike → record (issue comment + STATE + commit run dir with secret scan).
3. Explicit user asks go to the front; gates never pass on rollback or best-effort; blind judges on frozen packets.
4. Resume by appending tasks after cached calls (never edit the shared CTX); coordination rule for parallel applies.
5. Brief: live completeness critic + morning brief; update the map.
